## تحلیل از پیش ثابت
- ویژگی: خروجی لایهٔ features، یعنی Flatten پس از توجه و پیش از طبقه‌بند؛ ۴۸ مؤلفه.
- برای هر یک از ۱۲۰ مدل: محاسبهٔ silhouette در فضای اصلی ۴۸بعدی، بدون استانداردسازی اضافی ویژگی‌ها و با فاصلهٔ اقلیدسی.
- نمونه‌ها فقط از ۱۷ کاراکتر outer همان fold؛ ۱۲۰۰ رخداد شامل ۲۰۰ هدف و ۱۰۰۰ غیرهدف، مطابق نسبت اصلی ۱ به ۵. seed نمونه‌گیری 314159 است.
- در هر فرد/fold، شناسهٔ رخدادها برای هر چهار مدل و هر سه seed یکسان است. نمونه‌ها براساس درست/غلط‌بودن پیش‌بینی انتخاب نمی‌شوند.
- پیش از تحلیل، احتمال‌های تمام outer مجدداً محاسبه و با پیش‌بینی ذخیره‌شده مقایسه می‌شوند؛ در صورت عدم تطابق، کار متوقف می‌شود.
- برای شکل‌های t-SNE فقط مدل‌های seed=42، fold=1 برای A و B و چهار مدل استفاده می‌شوند: ۸ شکل ثابت. این seed/fold بهترین اجرا نامیده نمی‌شود و شکل‌ها براساس زیبایی انتخاب نمی‌شوند.
- t-SNE: دو بعد، perplexity=30، random_state=42، init=pca، learning_rate=auto، max_iter=1000، فاصلهٔ اقلیدسی، Barnes-Hut، angle=0.5.
- silhouette دوبعدی فقط برای همان ۸ شکل و جدا از silhouette اصلی گزارش می‌شود. عدد دوبعدی جانشین عدد ۴۸بعدی نیست.
- embedding هر مدل مستقل است؛ جهت محورها، مکان خوشه‌ها و مقیاس میان شکل‌ها مختصات مشترک ندارند.
- ویژگی‌های مدل‌های جداگانه کنار هم چسبانده نمی‌شوند؛ خلاصهٔ نهایی میانگین امتیازهای درون هر fold است، نه silhouette یک فضای ادغام‌شده.
- این تحلیل توصیفی است؛ جدایی ظاهری یا silhouette بالاتر اثبات مکانیسم توجه، برتری دقت یا معناداری آماری نیست. seed/fold آزمودنی مستقل نیستند.

## خروجی

- silhouette_48d.csv: امتیاز اصلی همهٔ مدل‌ها؛ ستون دوبعدی فقط در ۸ ردیف مصورسازی مقدار دارد.

## محیط و کنترل‌ها
از همان محیط قبلی استفاده کنید؛ TensorFlow/NumPy/Scipy را ارتقا ندهید. matplotlib نیز لازم است و نسخهٔ واقعی آن در گزارش ثبت می‌شود. اگر ModuleNotFoundError برای matplotlib دیدید، در همان محیط اجرا کنید:
python -m pip install "matplotlib>=3.7,<4"

آزمون محلی بدون TensorFlow:
python RUN_FEATURES_D25.py --self-test
