# تحلیل‌های تکمیلی برای نسخهٔ اصلی MSTA-CNN

این بسته اجرا شده و نتایج در results آماده‌اند. هیچ آموزش، تنظیم آستانه، انتخاب مدل یا استنتاج جدید انجام نشده است. احتمال‌های ذخیره‌شدهٔ همان Test رسمی مرحلهٔ ۲۶ دوباره امتیازدهی شده‌اند؛ checkpointها با منابع نسخهٔ primary تطبیق داده شده‌اند.

## بازتولید
با محیط قبلی:
python ANALYZE_METRICS.py

اجرای بدون آرگومان همهٔ جدول‌ها را از فایل‌های inputs بازتولید می‌کند. TensorFlow لازم نیست. numpy، scipy و scikit-learn کافی‌اند؛ نسخه‌های محیط واقعی در analysis_manifest.json ثبت شده‌اند. فایل msta.py عین هستهٔ مرجع قبلی است و در این تحلیل فقط ابزار امتیازدهی/برچسب را فراهم می‌کند.

آزمون مستقل:
python ANALYZE_METRICS.py --self-test

## خروجی‌های ده‌گانه
۱. binary_by_seed.csv: AUC، AP، balanced accuracy، MCC، حساسیت، ویژگی، precision، F1 و دقت رخداد؛ آستانهٔ ثابت ۰٫۵.
۲. binary_summary.csv: میانگین و انحراف معیار نمونه‌ای سه seed برای هر فرد و مدل؛ تمام معیارها بدون انتخاب گزینشی.
۳. wilson_character_accuracy15.csv: بازهٔ Wilson ۹۵٪ برای هر یک از ۱۲ مدل، با n=100.
۴. paired_errors_all_repetitions.csv: شمارش زوجی خطاها برای هر فرد/seed و هر تکرار.
۵. paired_errors_at15.csv: همان مقایسه برای معیار اصلی تکرار ۱۵.
۶. paired_character_details_at15.csv: شناسهٔ کاراکتر، حقیقت، دو پیش‌بینی و نوع اختلاف.
۷. row_column_errors_by_seed.csv: تفکیک خطای سطر، ستون و هر دو در تکرار ۱۵.
۸. character_error_details.csv: جزئیات تمام کاراکترها برای هر مدل در تکرار ۱۵.
۹. chance_and_baselines.csv: سطح شانس یکنواخت کاراکتر و خطوط پایهٔ رخداد؛ این دو سطح جدا هستند.
۱۰. design_quantities.csv: طول اسمی کرنل، فاصلهٔ گام توجه و نقش فیلتر مکانی، همراه محدودیت تفسیر.

## قواعد علمی
- معیار اصلی هنوز دقت کاراکتر در تکرار ۱۵ است. بهبود برخی معیارهای رخداد جایگزین آن نمی‌شود.
- هدف/غیرهدف نامتوازن‌اند: ۳۰۰۰ هدف و ۱۵۰۰۰ غیرهدف در Test هر فرد. دقت رخداد ۸۳٫۳۳٪ با پیش‌بینی همیشگی غیرهدف به دست می‌آید.
- AP براساس average_precision_score محاسبه شده؛ آن را مساحت ذوزنقه‌ای منحنی PR ننامید. مرجع ۱/۶، AP امتیازدهی ثابت و نسبت هدف است؛ ادعای امید دقیق هر رتبه‌بندی تصادفی محدود نیست.
- Wilson بازهٔ اسمی دوجمله‌ای برای مدل ثابت و فرد ثابت است؛ استقلال کاراکترها فرض می‌شود. بازه شامل تغییرپذیری آموزش و جمعیت افراد نیست.
- سه seed روی همان ۱۰۰ کاراکتر اجرا شده‌اند؛ آنها را ۳۰۰ کاراکتر مستقل نمی‌نامیم. هیچ بازهٔ Wilson روی میانگین seedها محاسبه نشده است.
- هم‌پوشانی بازه‌های Wilson آزمون اختلاف زوجی نیست. این بسته p-value یا ادعای معناداری تولید نمی‌کند.
- شناسهٔ کاراکتر از صفر شروع می‌شود. مقایسهٔ زوجی، همان موقعیت کاراکتر در همان فرد و seed را کنار هم قرار می‌دهد.
- شمارش تجمیعی روی seedها فقط تعداد تصمیم‌های کاراکتر–seed است. تکرارهای ۱ تا ۱۵ نیز نمونه‌های مستقل نیستند.
- فاصلهٔ اسمی گام توجه ۲۵۰ ms است. طول اسمی کرنل اولیه ۵۰۰ ms است؛ این اعداد علت عملکرد یا انتخاب‌پذیری P300 را اثبات نمی‌کنند.
- این تحلیل تکمیلی پس از مشاهدهٔ Test طراحی شده و توصیفی/اکتشافی است. آستانه و وزن‌های اصلی تغییر نکرده‌اند.
- Competition II در این بسته بازآزمایی یا تغییر داده نشده است. متن مقاله هنوز ویرایش نشده است.
